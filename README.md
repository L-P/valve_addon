# `valve_addon`

Sources of some of my GoldSrc maps along with the build scripts required to
compile them.

Released under the Creative Commons BY-NC-SA 4.0 license, see [LICENSE.md](./LICENSE.md).

External dependencies:
- [ericw-tools](https://ericwa.github.io/ericw-tools/) 2.0.0-alpha10 or > 2.0.0-alpha11
  (fix for [#495](https://github.com/ericwa/ericw-tools/issues/495) required)
- [goldutil](https://github.com/L-P/goldutil) latest master
- [tup](https://gittup.org/tup/) ≥ 0.8, available in Debian repositories
